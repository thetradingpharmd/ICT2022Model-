# TheTradingPharmD NinjaTrader 8 Indicators

A collection of free NinjaTrader 8 indicators developed by **TheTradingPharmD**, bringing ICT-based concepts and tools from TradingView into NT8.

These indicators are designed to help identify structured price action setups while keeping the charts clean and easy to use.

## Included Indicators

### ICT 2022 Model [TheTradingPharmD]

An NT8 conversion of my ICT 2022 Model indicator.

The indicator incorporates CISD and Fair Value Gap logic used to identify ICT 2022-style setups directly on NinjaTrader charts.

### IFVG Pro+ [TheTradingPharmD]

A standalone Inverse Fair Value Gap indicator built for NT8.

IFVG Pro+ identifies potential IFVG formations while using the same underlying concepts incorporated into my TradingView indicators.

## Installation

1. Download the `.zip` file for the indicator you want to install.
2. **Do not unzip the file.**
3. Open **NinjaTrader 8**.
4. Go to:

   `Tools > Import > NinjaScript Add-On`

5. Select the downloaded `.zip` file.
6. Allow NinjaTrader to complete the import.
7. Open a chart and right-click it.
8. Select **Indicators**.
9. Search for:

   - `ICT 2022 Model [TheTradingPharmD]`
   - `IFVG Pro+ [TheTradingPharmD]`

10. Add the indicator to your chart and configure the settings as desired.

## Import Error Fix

If you receive an error similar to:

`Could not find a part of the path ...\NinjaTrader 8\tmp\Import\Backup`

Close NinjaTrader and navigate to:

`Documents > NinjaTrader 8 > tmp`

Make sure the following folders exist:

`Import > Backup`

The completed folder structure should look like:

`Documents\NinjaTrader 8\tmp\Import\Backup`

If either folder is missing, create it manually.

Reopen NinjaTrader and attempt the import again.

If your Documents folder is synced with **OneDrive**, make sure you are modifying the NinjaTrader 8 directory that NinjaTrader is actually using.
